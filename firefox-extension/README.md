# Otosu Firefox拡張機能

## 一時的にインストールして試す

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」を選ぶ
3. このフォルダーの `manifest.json` を選ぶ
   - *※ GitHub Actions からダウンロードした zip ファイルを使用する場合は、一度 zip を解凍し、その中にある `manifest.json` を選んでください。*
4. YouTubeを開き、ツールバーのOtosuボタンまたは右クリックメニューを使う

Otosuを一度起動して `otosu://` プロトコルを登録してから使用してください。
